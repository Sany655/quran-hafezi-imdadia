## 🕋 The Divine Foundation & Purpose (আমাদের লক্ষ্য ও মূল দর্শন)

> **وَتَعَاوَنُوا عَلَى الْبِرِّ وَالتَّقْوَىٰ وَلَا تَعَاوَنُوا عَلَى الْإِثْمِ وَالْعُدْوَانِ**  
> *“তোমরা সৎকাজ ও তাকওয়ার ক্ষেত্রে একে অপরকে সহযোগিতা কর, আর পাপ ও সীমালঙ্ঘনের কাজে পরস্পরকে সহযোগিতা করো না।”*  
> — **সূরা আল-মায়িদাহ (৫:২)**

> **إِنَّمَا نُطْعِمُكُمْ لِوَجْهِ اللَّهِ لَا نُرِيدُ مِنكُمْ جَزَاءً وَلَا شُكُورًا**  
> *“আমরা তো কেবল আল্লাহর সন্তুষ্টির জন্যই তোমাদেরকে আহার্য দান করি; আমরা তোমাদের কাছ থেকে কোনো প্রতিদান ও কৃতজ্ঞতা চাই না।”*  
> — **সূরা আল-ইনসান (৭৬:৯)**

This project was conceived not as a commercial product, but as an **eternal continuous charity (*Sadaqah Jariyah*)** dedicated purely for the Countenance and Pleasure of Allah (*Li-wajhillah*).

Every line of code, every proofread word, every UI enhancement, and every share is an act of devotion to safeguard, beautify, and disseminate the Noble Quran.

### 🌟 Our Non-Profit Charter:
1. **100% Free Forever**: No paid tiers, no paywalls, no subscriptions.
2. **Zero Advertisements & Zero Tracking**: Uninterrupted, pure spiritual sanctuary with no ads, tracking pixels, or user monetization.
3. **Radical Authenticity (Zero Tahrif)**: Checked against certified scans (Imdadia Library 15-Line Mushaf) and Tanzil Project verified text cores.
4. **Collaborative Ummah-Driven**: Open to developers, scholars, Huffaz, designers, and students worldwide.

## ✨ Application Features (অ্যাপের মূল সুবিধাসমূহ)

- 📖 **Authentic 15-Line Imdadia Hafezi Mushaf**: High-resolution 612 page scans matching the standard South Asian Hifz curriculum where every page begins and ends with an Ayah.
- 🔤 **Word-by-Word Bengali Vocabulary**: Understand Quranic vocabulary directly with grammatical breakdown.
- 📚 **Dual Bengali Translations**:
  - *Taisirul Quran* (তাইসীরুল কুরআন - Tawheed Publication)
  - *Mawlana Mujibur Rahman* (মাওলানা মুজিবুর রহমান)
- 💡 **Authentic Tafsir**: Integrated explanation without doctrinal distortions.
- ⚡ **100% Offline SQLite Engine**: Blazing fast instant searches and zero latency even without an internet connection.
- 🔊 **Page Turn Experience**: Realistic flipping audio for an authentic Mushaf feel.
- 🔖 **Smart Bookmarks & Navigation**: Jump seamlessly between Surahs, Juz (Paras), Pages, and Ayahs.

## 🚀 Getting Started (Development Setup)

### Prerequisites:
- Flutter SDK (`>= 3.3.0 < 4.0.0`)
- Android Studio / VS Code
- Git

### Installation:
```bash
# 1. Clone repository
git clone https://github.com/Sany655/quran-hafezi-imdadia.git
cd quran-hafezi-imdadia

# 2. Get dependencies
flutter pub get

# 3. Run application
flutter run
```
